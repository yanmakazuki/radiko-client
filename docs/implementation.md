## 2026年10月15日：純RustでのADTS/SBRデコード

前段のSymphonia単独では未対応だった実配信のMPEG-2 ADTS／SBRを扱うため、`rusty_aac = 1.1.0`を追加した。Rust 1.85・Apache-2.0・実行時依存なしを公開クレートのソースで確認。既定featureを無効化したスカラー実装を採用し、Cライブラリ・FFI・OSのデコードAPI・外部プレイヤーは使用していない。採用APIとSBR処理は取得済み1.1.0のソースでも確認し、Cargo.lockで固定した。[公開API](https://docs.rs/rusty_aac/1.1.0/rusty_aac/)と[配布元](https://github.com/Remade-With-Rust/remade_ffmpeg_rs)を参照。

実装：

- `src/player/aac.rs`に状態を保持する`AdtsDecoder`を追加。MPEG-2／MPEG-4 ADTSの境界とID3の長さを検証し、先頭1パケットだけでなく取得したセグメントの全パケットをデコードする。
- 最大8MiB・4096パケット。CRC付き／複数raw block、PCE構成、AAC-LC以外のコアAOTは今回の接続範囲外として明示的に拒否。フレーム切断・同一セグメント内や前回からの構成変更も拒否し、失敗時に状態を破棄する。
- PCMは1パケットずつ生成・検証・破棄する。非数・不正なチャンネル数・フレーム数、コアの時間とPCM時間の不一致を成功扱いにしない。HE-AAC宣言では実際のSBR検出を要求し、SBRを検出しても出力がコアレートのままなら拒否する。
- CLIにパケット数、コア／出力レート・チャンネル数、SBR検出、出力拡張、PCM時間、処理時間、非ゼロサンプル数を追加。認証情報・配信URL・圧縮音声・PCMはログやファイルに保存しない。
- 非ADTSは従来のSymphonia経路を使う。HE-AAC宣言の非ADTSは新AACデコーダーへ未接続で、AACコアだけの成功とは扱わない。
