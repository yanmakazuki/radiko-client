## 2026年10月16日：タイムフリーの開始位置指定・再生中シーク

`play-timefree`に`--offset SECONDS`と`--interactive`を追加した。対話操作は`seek 秒数`、`+15`、`-15`、`q`をEnterで確定する。相対移動は出力済みPCMの位置が基準で、未出力バッファや無音補填分を含めない。ライブと枠外のシークを拒否する。

配信側の根拠と実装：

- [公開参考実装のタイムフリー取得](https://github.com/garret1317/yt-dlp-rajiko/blob/master/yt_dlp_plugins/extractor/radiko_hacks.py)で`seek`の使用を確認し、実配信の応答で検証した。公式に保証されたAPI仕様としては扱わない。TBSのHLSではPROGRAM-DATE-TIMEを確認し、冒頭は12:00:00.005、次は12:00:05.040、次は12:00:10.074 JSTだった。
- 放送枠・認証・契約・配信条件の確認を共用し、枠外位置は配信認証前に拒否する。`ft`／`start_at`と終了日時を元の枠に維持し、`seek`を希望位置の約10秒前、取得窓`l`を60秒とする。位置とHLS時刻を対応付けられなければ推測せず失敗する。
- 新しいデコーダーで直前からデコードし、指定時刻より前のPCMを切り上げフレーム数で捨てる。枠末尾までの残り時間を出力上限に使う。表示位置は開始位置＋出力済みフレーム／レートで更新する。
- `player::seek::Controller`は単一準備ワーカー、容量1の最新要求メールボックス、容量1の結果チャネルと要求世代を持つ。古い準備を取り消し、配送済みの古い結果も破棄する。同じ局ID＋開始日時・終了日時の放送枠だけを受け入れる。
- 主再生を続けながら、2秒分（末尾付近は残り分）の検証済みPCMと新しい出力機器を準備する。成功後に旧世代の停止・stream解放・キュー破棄を行う。失敗時は旧出力を維持する。親子の停止トークンで全体終了と世代終了を分離し、旧世代の終了が新しい出力を止めないようにした。
- CPALはenabledになるまでキューを消費しない。初期PCMが短い場合も2秒分をためてから出力を開始する。HLS更新待ちは取得開始時点から数え、応答待ち時間を重ねて加算しない。

## 2026年10月16日：先頭1セグメントのCPAL音声出力

純RustのADTS/AAC・SBRデコードから、実機の音声出力コールバックへPCMを渡す経路を追加した。連続再生は今回の段階では実装していない。

追加したコマンド：

```sh
cargo run -- probe-output 1
cargo run -- play-sample OBS
cargo run -- play-sample TBS
cargo run -- play-sample TBS 20261015120000
cargo run -- play-sample TBS 20261006120000
```

実装：

- `player::aac::AdtsDecoder::decode_segment_pcm`は最大4MiBのPCMを保持し、全パケット・SBR・時間長などの検証成功後だけ返す。失敗時はPCMを返さずデコーダー状態を破棄する。PCMのDebug出力は要約のみ。従来の`probe-live`／`probe-timefree`はPCMを保持せず音声出力しない。
- `stream::probe_for_output`は既存のプローブと同じ放送枠・認証・地域・契約・番組条件の確認を使い、明示的な出力要求時だけPCMを返す。圧縮音声・PCM・認証情報・署名付きURLは保存／ログ出力しない。
- `player::output`に[CPAL 0.16.0](https://docs.rs/cpal/0.16.0/cpal/)と[rtrb 0.3.2](https://docs.rs/rtrb/0.3.2/rtrb/)を追加し、取得したバージョンのソース・APIとCargo.lockで確認した。依存の宣言MSRVはそれぞれ1.70と1.38。CPALは出力I/Oのみで、OSデコーダーや外部プレイヤーは使用していない。
- PCMと同じレートのmono/stereo・f32対応構成を選び、2秒分の固定容量SPSCキューに左右のフレームを格納する。生産側だけ満杯時に待機し、音声コールバックには待機・割り当て・ロック・通信・デコードを持ち込まない。ゲインは0.25固定。不足時は無音にし、メディア位置は進めない。
- サンプル末尾を総フレーム数で制限する。ライブは取得後に残り時間を算出し、CPALの再生予定時刻を考慮して期限以降の出力を無音化する。終了／エラー時は停止フラグ、streamのpause／drop、キュー破棄を行う。コールバックが3秒進まなければ失敗して停止する。
