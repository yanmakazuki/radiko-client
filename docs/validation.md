## 次の作業

1. 数十分以上の停止／再開など、既存経路の実機確認を追加する。ライブから章への切替と124.8秒の停止は成功済み。大量一覧の描画最適化は50,000枠のオフライン確認と60.8秒の実配信操作回帰が成功済み。
2. 実機の出力機器切断・再接続とエラー時の復元を、通常のfixtureテストと分けて確認する。
3. 異なるイベント原点の実例を取得し、音声との関係を確認できた場合だけ補正を実装する。
4. 全局の聴感品質やPSの明示シグナル、非ADTS形式の成立条件は、確認できたAAC/SBRのケースと分けて調べる。

通常の`cargo test`はアカウント・実通信に依存しない。明示的な長時間検証は[README](../README.md#チャプターと検証範囲)のスクリプトで実行する。録音・音声の永続保存・外部プレイヤーへの置換は行わない。
