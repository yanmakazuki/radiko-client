## 次の作業

優先調査：後続ビルドa7007461のTBS 10月6日枠の30分再試行は1060.3秒・不足139,264フレームの後に停止した。ca0b3d46の1000秒位置から120.6秒は不足0で成功したが、冒頭からの再試行では1107.4秒までに不足70,144フレームを観測。1154.8秒・25操作まで停止は再現せず、ユーザー指示で中断した。30分成功には含めず、同じ位置付近の不足と先の停止原因を継続調査する。過去ビルドの成功と区別する。

1. 既存経路の実機確認を追加する。ライブから章への切替、124.8秒と1,800.4秒の停止・再開は成功済み。大量一覧の描画最適化は50,000枠のオフライン確認と60.8秒の実配信操作回帰が成功済み。全国30日分の部分取得・実機応答も別途確認済み。
2. USB切断・再接続と明示的再生は確認した。実機の機器エラー経路とエラー後の復元は引き続き未検証。
3. 異なるイベント原点の実例を取得し、音声との関係を確認できた場合だけ補正を実装する。
4. 全局の聴感品質やPSの明示シグナル、非ADTS形式の成立条件は、確認できたAAC/SBRのケースと分けて調べる。
